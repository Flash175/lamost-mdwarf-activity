
# 复现流程 4.10（Metallicity: a measured vertical gradient that cannot supply the missing channel）

对应正文 **§4.10**：金属度确实有垂直梯度，但两个理由使它无法承担"亚型内部那三分之二"——
①在 |Z| 固定下 [Fe/H] 与活动率的关系太小（−0.5 pp / 15.8 pp ≈ 3%）；
②[Fe/H] 与亚型/Teff 强退化，控制亚型后**符号反转**（固定效应 −1.51，即富金属星更不活跃）。

## 预期结果（实测 52/52 PASS）

**覆盖**：[Fe/H] 可用 **584,029 颗（91.54%）**，中位误差 **0.120 dex**；切 |err|≤0.25、−2≤m_h≤0.6 后不再加别的条件。

**可用子集 vs 全样本活动率**（六档）：23.29/12.57/7.51/6.42/7.39/12.34 对 23.81/12.90/7.78/6.65/7.76/13.24 per cent。

**垂直梯度**：中位 [Fe/H] = −0.085 / −0.114 / −0.154 / −0.201 / −0.203 dex（<100 → 600–1000 pc），
首 kpc 内降 **0.12 dex**；线性拟合 **−2.31×10⁻⁴ dex pc⁻¹**、**r = −0.195**（584,029 颗）。

**|Z| 固定下的四分位**：顶减底 **5.70 / 3.85 / 2.65 / 2.20 / 0.93 pp**；
全局 logit 斜率 **+0.5881 ± 0.0197**（z ≈ 30），把 Δ[Fe/H] = −0.0692 dex 传进去只贡献 **−0.499 pp**，
对同一子样本 15.78 pp 的降幅而言是 **3%**。

**退化与反转**：亚型中位 [Fe/H] 从 **−0.21（dM0）到 +0.23（dM6）**；亚型内与 Teff 相关 **+0.423 / −0.433**；
<100 pc 的贫金属四分位含 **15.1%** 晚型（dM4–dM6）、富金属四分位 **69.1%**（dM4 单独为 13.1% vs 46.4%）；
固定效应拟合 **−1.5141 ± 0.0242**（z = −62.6），逐亚型斜率 **+0.55（dM0）**、−1.52 / −0.83 / −1.34 / −2.07 / −2.21 / −4.14 dex⁻¹，
通道预算因此变成 **+1.29 pp**（不是减少而是增加）。
