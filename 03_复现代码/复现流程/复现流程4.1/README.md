## 预期结果（实测 60/60 PASS）

**逐亚型（>400 pc 对 200–400 pc，637,973 样本）**：dM0 5.27/5.05（58,235 与 65,497 颗）、dM1 7.01/5.60、
dM2 13.03/9.25、dM3 15.68/11.62、dM4 20.66/14.53；dM5 33.85/36.38；dM6 33.33/52.63（仅 24 条谱）。

**组成杠杆**：固定内层权重后，逐亚型速率变化合计 **+2.41 pp**（dM4 +1.68、dM2 +0.67 主导；
dM5/dM6 为负）。dM4 占内层权重 **27.8%**、却只占远区 **2.1%**，因此合并比例仍下降 **0.76 pp**。

**亚型占比**：dM0 从 34.3% 升到 54.0%，dM5 从 1.37% 降到 0.56%。

**漂移**：dM4 的 Teff 中位 3,351→3,421→3,506→3,546 K（<100/200–400/400–600/600–1000 pc），
S/N 16.8→8.7→5.0→2.8；dM2 到 3,622 K/7.0；dM5 到 3,471 K/2.6（400–600 pc），其 600–1000 pc 箱
（143 颗）为 3,354 K/2.5。近平面参考：dM1 3,670 K、dM2 3,517 K、dM4 3,351 K。

**逐型贡献（内层权重固定）**：dM0 +0.04、dM1 +0.27、dM2 +0.66、dM3 +0.26、**dM4 +1.70**、dM5 −0.19、dM6 −0.32 pp，合计 +2.41 pp。

**组成归一后的合并值**（把每档重加权到内层组成）：200–400 pc 12.21%、400–600 pc **13.98%**、600–1000 pc 18.05%、
>400 pc 14.62% —— 组成控制后不再下降（12.21 → 13.98 反而回升），与正文"the composition-controlled value stops declining"一致。

**200–400 → 400–600 的拆分**：rate **+1.334**、comp **−1.614**、inter **−0.849**、合计 **−1.129 pp**（附录 Table 9：+1.333/−1.613/−0.850/−1.130）。
## 两点说明

1. **一节之内两个样本**：逐亚型比例、合并降幅 0.76 pp、速率效应 +2.41 pp、内层权重 27.8%、dM4 占远区 2.1%、
   dM4 的 Teff 序列来自 **637,973**；S/N 中位、600–1000 pc 星数（324/143）、dM2 与 dM5 端点来自
   **639,711（去巨星前）**。正文已加一句口径说明；两项对样本不敏感的量（+2.41 pp 与 27.8%）在两个样本里一致。
2. **正向/反向贡献**：dM0–dM4 的远区比例高于 200–400 pc，dM5/dM6 更低；合并值下降是因为混合比例
   迅速向早型（低活动）倾斜——这就是"组成杠杆"。
