## 本轮按复现结果改正的两处正文数值

1. **`287 \pm 3` → `287 \pm 3.5` pc**：`lnf_fit_coefs.csv` 的 M3（指数+亚型固定效应）内盘拟合
   b = −3.482751 ± 0.042045 kpc⁻¹，delta 法给出 H = 287.1 ± 3.5 pc。正文已改；
   对应检查项 `inner subtype-controlled H (287)` 与 `inner subtype-controlled H se (3.5)`。
2. **`8.57 / 17.77`%（5,832 / 349 颗）→ `8.59 / 18.00`%（5,834 / 350 颗）**：原数字出自
   `maglimit_tests.csv` 的 637,352 星旧样本（<100 pc 176,664 颗，比冻结样本少 464 颗），
   与本节其余数字所用的 637,973 冻结样本不同口径。正文已按冻结样本重算值改写；
   检查项 `G<=16.5 n/pct 400-600`、`G<=16.5 n/pct 600-1000` 直接与冻结样本量比对（容差 0 颗 / 0.006 pp）。
   旧样本的 5,832 与 17.77 仍保存在 `输出/step1_values.csv` 的 `maglim n/pct` 两行作对照，不再与正文比对。

3. **`20 to 100 per cent` → `20 to 90 per cent`**：C1（Teff 收窄到中位 ±100 K）到 C2（远盘重加权到近盘 Teff 分布）让晚型"超出 1 的部分"减少 **26.5 / 19.5 / 32.7 / 41.2 ％**（dM2/dM3/dM4/dM5）；若把两步一起算（原始比值 → C2）则为 **25.2 / 34.8 / 46.9 / 90.1 ％**。两种口径的包络是 19.5–90.1，正文原写 20–100 没有对应口径，现改为 **20–90**（检查项 `drift share lower (20)`、`drift share upper (90)`、`drift share reweighting only dM2/dM5`）。
