## 预期结果（实测 47/47 PASS）

**K 侧（未清理 6,111 谱，正文 §3.6 第一段）**：1.4（282）、1.1（566）、0.0（72）、1.4（1,317）、

K1−K4 = **1.86 ± 0.94 pp**（2.0σ）。

**K 侧（清理后 5,047 谱，Teff 轴与边界）**：合计 **1.74%**；Teff 轴 **0.00–4.34%**（正文 0.0–4.3）；
边界 3,900–4,000 K：**392 谱 4.34%**；4,000–4,100 K：**235 谱 1.70%**；4,100–4,200 K：**283 谱 2.12%**；
4,250 K 以上 0.00–3.45%（32–587 谱/箱）；S/N∈[6,20] 匹配后最大位移 **0.99 pp**（正文给的上界 1.9 pp，成立）。

**M 侧**：逐谱 7.0、8.1、13.6、16.4、20.9、58.0、71.3（dM0–dM6）、69.9、57.3；
可探测 40.2 / 30.6%；S/N 6–20 匹配后 **89 / 7** 颗（637,973 口径）。

## 三点说明

1. **两个 K 侧样本都用上了**：未清理 6,111 谱给"逐型比例 + χ² + K1−K4"；清理后 5,047 谱
   （ruwe<1.4、σlogg<0.5、σT<200 K、4.0<logg<5.2）给"Teff 轴 + 边界三值 + S/N 匹配"。
   两者合计比例不同（2.03% vs 1.74%），正文已分别标注（Teff 轴那句写 1.7%）。
2. **S/N 匹配是单侧界**：正文说"不移动超过 1.9 pp"，清理样本实测最大 0.99 pp，故成立。
3. **M 侧两个逐星口径**：40.2/30.6% 与 89/7 用 637,973（去巨星后）；若用 639,711（去巨星前）
   则为 41.1/33.0% 与 91/7 —— 正文统一采用 637,973，本流程两个都给，便于核对。
