**探测效率与一致性**：P(Hβ\|Hα) = 74.6%（S/N 20–40）、84.9%（>40）、44.4%（5–10），即正文的 **75–85% → 44%**；两条线都 >3σ 的谱 **327** 条，$r=0.77$、对数斜率 **0.98**。

**$L/L_{\rm bol}$ 判据**：比例 18.58 / 9.71 / 5.78 / 5.48 / 6.76 / 12.27%；降幅 **2.75**（EW 判据 3.06）；$10^{-4}$ 对应 EW 从 **0.86 Å（dM0）** 到 **19.08 Å（dM7）**；两判据差从 **0.6 pp（dM0）** 单调升到 **36.5 pp（dM6）**。
