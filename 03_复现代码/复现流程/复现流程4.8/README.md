
# 复现流程 4.8（The hot end: no monotonic trend）

对应正文 **§4.8**：K 型（热端）试点的活动比例沿 Teff **没有单调趋势**；但两套 EW 管线与两套 Teff 标度不可比，
所以本节的数字只作"K 侧内部"的陈述，不与 M 侧活动率比大小。

## 预期结果（实测 32/32 PASS）

**原始 6,111 条**（七个子类型箱，K6 无成员）：χ² = **29.83**（6 dof，p = **4.2×10⁻⁵**），
由 K7 **3.93%**、K4 **2.92%** 偏高与 K1 **1.06%** 偏低驱动。

**清理后 5,047 条**：16 个 100 K 的 Teff 箱，比例 **0.0–4.34%**；**Spearman ρ = −0.107（p = 0.69）**，
既不单调升也不单调降。

**EW 分位**（原始试点）：各亚型 EW 中位**全为负**（K0 **−1.014** Å，K7 **−0.274** Å）；
90 分位最高只有 **+0.088** Å；0.75 Å 判据通过率 **0.00%（K2）–3.93%（K7）**。

**三段分解**（`m_side_three_units.csv`）：dM5 逐谱 **58.008**、逐星 **57.812**、逐星+2D 裁剪 **56.771**；
dM7 **69.948 / 70.860 / 73.253** —— 同量在三种口径下相差 1.2 与 3.3 个百分点，来源是"谱→星"和"2D 裁剪"，
不是 EW 管线。

**试点选择范围**（清理后逐谱表实测）：G 14.00–18.00、S/N 5.1–30.0、log g 4.00–4.90、Teff 3,901–5,494 K
（原始选择为 G 14–18、S/N 4–30、log g > 3.8、Teff 3,900–5,500 K，清理只收紧了 log g 与 S/N 下缘）。

## 本轮修正的两处表述（已在正文）

1. **样本归属**：原文把"16 个 Teff 箱、0.0–4.3%"挂在 6,111 条上，实际是**清理后 5,047 条**；
   现已拆成"6,111 条 → 七个亚类型箱（χ² = 29.8）／清理后 5,047 条 → 16 个 Teff 箱"。
2. **措辞**：补"K6 无成员"、把"Wilson 与 χ² 区间偏乐观"改为"χ² 与任何二项区间偏乐观"、
   把"不报跨管线比值与显著性"改为"不报 K/M 比值或跨管线显著性"、图号按升序写成 Figures 6 and 7，
   并把"无单调趋势"用 Spearman 检验坐实（ρ = −0.11，p = 0.69）。

## 与 §3.6 的分工

`复现流程3.6/` 负责**产生** K 侧数字（6,111 条原始计数、5,047 条清理、面积与 S/N 匹配、边界三值、χ² 与 M 侧逐谱比例）；
