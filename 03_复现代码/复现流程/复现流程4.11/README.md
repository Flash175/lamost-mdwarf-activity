## 复现的关键量

1. **降幅口径**：`0<|Z|<=100` 与 `200<|Z|<=400` 的活动率之差，按"全部亚型"计 = **16.028 pp**；只取 dM0-dM6 = **15.890 pp**。正文 §4.11 的 16.03 用前者，亚型分解用后者 —— 两者差 0.14 pp 全部来自 dM7-dM9（621 颗星）。
2. **RUWE 通道**：`RUWE<1.2` 去掉 4.30%（610,537 颗）-> 15.794 pp；`RUWE<1.1` 去掉 13.57%（551,389 颗）-> 15.571 pp。逐亚型位移与 `双星剔除_亚型降幅.csv` 逐格一致（容差 1e-4）。dM5 位移 0.595 / 1.709 pp，dM6 位移 1.089 / 4.461 pp；dM6 在 200-400 pc 档只有 **114** 颗（RUWE<1.2 后 110、<1.1 后 94）。
3. **RV 通道**：多历元 **131,183** 颗（20.6%）；χ² 判据命中 53.4%，峰峰判据 25.7%，并集 **70,660** 颗、实际剔除 **70,633** 颗（11.07%）-> 降幅 15.932 pp（变动 0.096 pp）。逐亚型最大位移 dM3 0.619 pp。RV 变星在激活星中占 **15.22%**、未激活星中占 **10.42%**（全体 11.07%）；200-400 pc 档为 16.88% / 10.17%。
4. **Ro x [Fe/H]**：周期样本 3,340 颗，其中 **2,984** 颗有可用 [Fe/H]（中位误差 0.110 dex）。逐亚型 Δβ = -0.079±0.254（dM0, 768）、+0.220±0.309（dM1, 540）、-0.273±0.460（dM2, 515）、+0.105±0.422（dM4, 643），精度加权 **0.010±0.166**，故 2σ 上界 |Δβ| <= **0.342**（正文 0.35）。两半星数 257-385。

## Ro x [Fe/H] 段落的一处实质修正（2026-11-08）

原句用 "the halves hold only 257--385 stars each" 解释"检验不够决定"，但那 257--385 是 **按 [Fe/H] 二分后的全部星数**，
真正进入拟合的只有 **未饱和段（Ro > 0.132）** 的星，两个半样本各只有 **49--209 颗**。已改为：

- 说明被略去的亚型及原因：dM3 / dM5 / dM6 在断点以上分别只有 **20 / 28 / 3** 颗；
- 补一致性：四个 Δβ 对加权均值的 **chi2 = 1.0（3 dof）**；
- 补检验力度：两半的 [Fe/H] 对比度 **0.18--0.27 dex**，是 §4.10 中 |Z| 梯度（0.069 dex）的 **2.6--3.9 倍**；
- 把 "halves hold 257--385" 换成 "only 49--209 stars per half enter the fit（the [Fe/H] halves themselves hold 257--385）"；
- 把 "the tau_c calibration itself is not metallicity dependent here" 改为限制式表述：采用的 **tau_c(M) 校准不含 [Fe/H] 项**，
  因此本检验无法探测"固定自转周期下发电机效率的金属度依赖"。

对应 8 项新 check（chi2、20/28/3、49/209、0.18/0.27）已加入 step2，现为 **109 项**。
