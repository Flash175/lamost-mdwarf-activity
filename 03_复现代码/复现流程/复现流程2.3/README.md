# 复现流程 2.3（2D vs 6D 可用性）

对应正文 **§2.3 "Which bins are usable: 2D versus 6D"**。本子流程从原始目录重建 6D 远区逐星表，
再把该节引用的所有数字与产出表逐项比对。

## 运行

```powershell
cd 复现流程2.3
python run_all.py
```

- `step1_6d_far_region.py`：重建 `|Z|>400 pc` 的 6D 样本（316 颗），输出
  `../../数据/6D远区_逐星_316颗.csv`（uid、subclass、G、M_G、S/N、logg、Teff、距离、|Z|、z_gc、active）
  与 `输出/step1_6d_far.json`；约 15 s（需读 563 MB + 117 MB 原始表）。
- `step2_check_23.py`：26 项比对，输出 `输出/step2_check.csv`；有 FAIL 时返回码 2。

## 一个容易误读的地方（不是错误）

正文 §2.3 的「7.11 → **7.07%**」是**只移除 6D 标记出的 316 颗**：
(7,090 − 61)/(99,684 − 316) = 7.029/99,368 = 7.074%。
而 `giant_cut_by_MG.csv` 的 `>400` 行给的是**移除全部 992 颗亮天体**后的 7.0239%。
两者分母不同、都对；比对脚本同时校验了这两个数（7.11 与 7.02）。
