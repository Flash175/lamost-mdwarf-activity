## 两点说明

1. **"可用天体测量"星数已与正文对齐**：正文原先写 3,142，本流程复算为 **3,150**（试图反推 3,142 的四种口径分别为
   3,139 / 3,145 / 3,143 / 3,139，均不吻合），已按复算值把正文改为 3,150；这 8 颗对任何斜率都无影响。
2. **误差的可复现性依赖 bootstrap 种子**：β 本身的点值稳定（±0.002），而 bootstrap 半宽有 ±0.003–0.005 的抖动，
   这就是图注 0.178/0.083 与本流程 0.175/0.079 的来源。点值（−0.890、−0.822、−0.857、0.068）逐位一致。

## 补充说明（Ro 构造与 Figure 2）

* **Ro 的构造**：$Ro=P_{\rm rot}/\tau_c$，$\tau_c$ 由冻结表的 $P/Ro$ 反推，中位 **33 d**、范围 **15.5–78.1 d**；
  $Ro$ 覆盖 0.002–2.405，$sRo/Ro$ 中位约 0.02。这确认了冻结表内部自洽（同一套 $\tau_c$ 归一化）。
* **Figure 2 复现**：两面板共 2,083 + 1,245 点，未饱和段（$Ro>0.132$）819 + 187 点；
  固定断点拟合斜率 $-0.890$ / $-0.822$，与图注逐位一致；重画图见 `输出/fig_rossby_repro.png`（不覆盖正文图）。
