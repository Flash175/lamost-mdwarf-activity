
# 复现流程 4.3（A six-quantity decomposition of the within-subtype decline）

对应正文 **§4.3**：把活动率随 |Z| 的下降拆到"我们真正测到的六个量"头上，看它们能解释多少。
结论：只有 **31 / 38 per cent** 的降幅能被这六个量的重分布产生，其余发生在**亚型内部**且不被任何已测量承载。

## 方法（与正文一致）

- 线性概率模型：`active ~ 1 + {亚型哑变量, Teff, log g, [Fe/H], log10 S/N, log10 d}`，**三档合并拟合一次**（系数共用）；
- 六量取遍 $2^6=64$ 个子集，Shapley 权重 $|S|!\,(K-|S|-1)!\,/\,K!$，每个子集的贡献 = 该档预测平均活动率 − `<100` pc 档的预测平均活动率；
- 各项之和精确等于全模型差（机器精度，$10^{-15}$ 量级）；
- 因系数共用，它衡量"这些量的重分布能产生的那部分降幅"，**不是**因果效应、也不是 Oaxaca 分解。

## 两点说明

1. **R3 logit 是归档值**：正文的 3.27 / 6.11 来自归档备忘（`数据/六因素分解_第二轮结果与审核备忘_v2.md` 第五节，脚本 s635）。
   本流程用逐星 IRLS logit + 64 子集**独立重算**得 3.390 / 6.276，与归档值差 **0.12 / 0.17 pp**（检查项按 ≤0.2 pp 通过）。
   差异来自 logit 的实现细节（收敛判据与预测均值口径），不影响"解释总量只移动不到 0.2 pp"的结论。
2. **"0.02–0.68 pp"的范围**：正文原来写 0.05–0.68，其中 0.05 只是 logit 档（200–400 pc）的变化、0.68 是 125/250 边界档的变化；
   把 R5 的 200–400 pc 档（0.017 pp）与独立 logit 重算（0.015 pp）也算进来，真实范围是 **0.015–0.675 pp**，
   已按复现结果把正文改为 **0.02–0.68**（对应检查项 `explained-total change lower incl. R5 (0.02)`）。
