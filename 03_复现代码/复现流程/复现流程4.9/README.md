## 本流程负责的四组量（实测 40/40 PASS）

**① 三档二项误差**（由 n、p 直接算 σ² = (1−p)/(n p)）：
**0.0043 / 0.0063 / 0.0079**（精确值 0.004251 / 0.006283 / 0.007875）。

**② 两套三点拟合**（都取自 `lnf_binfit.csv` 的 fits 段）

| 拟合 | a | b (pc⁻¹) | H (pc) | 残差（<100 / 100–200 / 200–400） | χ² |
|---|---|---|---|---|---|
| 未加权（§4.2/§4.4 引用） | −1.2262 | −0.004920 | 203.2 | **+0.064 / −0.107 / +0.043** | **537** |
| 二项加权（§4.9 讨论的那条） | −1.1783 | −0.005198 | **192.4 ± 1.5** | **+0.031 / −0.114 / +0.072** | **470** |

- 正文引用的 +0.031/−0.114/+0.072 与 χ² = 470 属于**二项加权**那条（归档 χ² 是拟合最小值；用报告系数重算得 466.5）；
- 残差/误差比 |r|/σ 为 **7.3** 与 **18.2**，即正文的 "7–18 times the binomial error"。

**③ 逐星 logit 内盘拟合**：b = **−0.004961 ± 0.000040** pc⁻¹ → H = **201.6 ± 1.6 pc**（正文 "H = 202 ± 2 pc"）。

**④ 逐亚型阈值换算**（`表2.6_Lbol_逐亚型.csv`，同一批星、同一 3σ）：等效 EW 阈值
**0.86 Å（dM0）→ 5.70 Å（dM6）**；"过 EW 但未过 L" 的比例在 dM0–dM6 上**严格单调**：
0.60 → 0.82 → 2.38 → 4.65 → 5.97 → 20.56 → **36.53** pp；
dM7/dM8（仅指示性）分别为 3.1% 与 4.7%（其"过 EW 未过 L"为 71.6 与 61.2 pp，正文只引到 dM6）；
去掉 3σ 会使 L 比例上升 **0.75（dM0）/ 0.99（dM1）pp**——即 `pct_lA − pct_lB`，说明两判据用的是同一 3σ。
