- 合并倍数：**3.06**（23.81/7.78）、**3.58**（23.81/6.65）、**3.35**（23.81/7.11）；
- 逐型 near→far：13.0→5.0、14.4→5.6、20.8→9.2、23.6→11.6、25.1→14.5、64.6→36.4、74.8→52.6；倍数 **1.42–2.57**；
- dM0 星数：35,091（<100 pc）与 65,497（200–400 pc）。

## 三点说明

1. **口径**：活动率一律基于 **2D 逐星样本**（637,973 颗，每星一条最大 EW 谱）；6D 子样本（82,518）只用于运动学与远区审计。
2. **逐型数值用去巨星后的 `*_cut` 列**：dM6 的 52.6 来自 `far_cut`；若用去巨星前的 `far_now` 会得到 50.8，两者不可混用。
3. **分类/Teff 匹配的 2.43–2.75 与 1.08–1.39** 属 §4.1 的稳健性检验，本流程不重复（数据见 `typing_tests.csv`）。
