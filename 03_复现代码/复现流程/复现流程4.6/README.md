## 预期结果（实测 75/75 PASS）

**冷端三档的活动率与 Wilson 95% 区间**

| 亚型 | n | 活动率 % | Wilson 95% |
|---|---|---|---|
| dM6 | 3,671 | **72.9** | 71.4–74.3 |
| dM7 | 483 | **74.7** | 70.7–78.4 |
| dM8 | 85 | **65.9** | 55.3–75.1 |

dM6↔dM7、dM7↔dM8 的区间都**相交**，所以"dM6 到 dM8 之间没有可确立的拐点"。

**S/N 匹配后**（3–6、6–12、6–20）：dM6/dM7 = **73.6/76.0、71.9/68.9、73.4/75.3**，三档都重叠；
但 dM8 匹配后只剩 **15 / 6 / 7** 条谱（正文"6–15"），而"3σ(EW) ≤ 0.75 Å"的可探测比例从 dM6 的 **63.9%** 掉到 dM8 的 **30.6%**。

**第三判据（线心高度 > 3× 线外噪声）**

- 存档 2,498 条谱里，按目录判据属于"活动"的 2,255 条中有 **437 条（19.4%）**不通过该判据；
- 另一批 5,999 条抽样谱按 |Z| 分档，不通过率为 **13.1 / 22.2 / 36.4 / 36.8%**（<100 / 100–200 / 200–400 / >400 pc）——**随距离单调上升**；
- 2,498 条存档谱里逐亚型为 **19.7 (dM0)、26.4 (dM1)、17.8 (dM2)、26.0 (dM3)、19.9 (dM4)、11.8 (dM5)、13.2% (dM6)**；
- **18.9%** 的"非活动谱"也通过该判据——这就是判据自身的噪声底。

因此正文的结论是：第三判据是一个**随距离变化的探测效应**，把它补全只会放大而不是清理 |Z| 趋势。

## 本轮按复现结果改正的一处正文归属

原文把逐亚型的七个百分比写成了"另一批 5,999 条抽样谱"的副产物（引文）：
> A separate draw of 5,999 spectra, binned in |Z|, gives failure rates of 13.1, 22.2, 36.4 and 36.8 per cent, **with per-subtype values of 19.7 (dM0) ... 13.2 per cent (dM6)**; 18.9 per cent of the inactive spectra also pass ...

复现后发现：**|Z| 分档的四个数确实来自 5,999 抽样**（13.149 / 22.214 / 36.395 / 36.842），
而**逐亚型的七个百分比和 18.9% 都来自那 2,498 条存档谱**（19.7/26.4/17.8/26.0/19.9/11.8/13.2，以及 18.93%）。
用 5,999 抽样算逐亚型会得到 21.2/27.8/20.5/29.1/22.0/12.2/12.5，与正文不符。
正文已改为显式区分两个样本：`... 36.8 per cent. In the 2,498-spectrum archive the per-subtype values are ...`。

## 本轮补进来的内容：把冷端数字从样本重算一遍

原先这些量是直接从 `表3.4_冷端.csv` 读的。本流程现在**从 637,973 冻结样本重建**（目录 → Gaia 并表 → 视差质量/ruwe → 每 uid 取最大 EW → M_G≥6 → |Z|≤3 kpc），得到：

| 亚型 | n | 活动率 | Wilson 95% | 可探测比例 |
|---|---|---|---|---|
| dM5 | 22,932 | — | — | 72.855 % |
| dM6 | 3,671 | 72.868 % | 71.407–74.282 | 63.934 % |
| dM7 | 483 | 74.741 % | 70.681–78.411 | 40.166 % |
| dM8 | 85 | 65.882 % | 55.313–75.078 | 30.588 % |

与归档表逐位一致。Wilson 区间用一般式：中心 (p+z²/2n)/(1+z²/n)、半宽 z√(p(1−p)/n+z²/4n²)/(1+z²/n)（z=1.96）；可探测比例 = 3σ(EW) ≤ 0.75 Å 的星占比，直接从 `ewha_err` 列算，不依赖归档表。

另外把第三判据的**定义**也做了自检：两张抽样表里 `pass_c3` 与 `peak > 3 * rms_norm` **完全等价（0 处不一致）**，并用这条规则独立重算全部失败率（19.4 %、13.1/22.2/36.4/36.8 %、逐亚型 7 个、非活动 18.9 %），与存档标志列逐位相同。

因此 §4.6 的每一个数字现在都有两条独立路径：归档表读取 + 从样本/原始列重算。

## 说明

- "活动"一律用**目录判据**（`active_cat` 列）而不是 EW 判据（`active_ew`）：用后者只有 911 条活动谱、失败率 0.11%，与正文完全不符。
- |Z| 分档的四个不通过率是在**活动谱内**统计（全部谱会给出 17.0/29.2/45.8/45.5）。
- 5,999 抽样里 dM7/dM8/dM9 极少（20/2/4 条），故逐亚型只报到 dM6。
- 正文最后一句"S/N ≥ 30 的晚型谱若把 dM8 压到 dM7 以下 3σ 则结论被推翻"是**未来检验的判据**，不含测量值，本流程不设检查项。
