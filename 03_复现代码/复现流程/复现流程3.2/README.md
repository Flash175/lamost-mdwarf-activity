## 预期结果（实测 63/63 PASS）

**① 探测比例**（3sigma(EW) <= 0.75 A 的星占比，2D 逐星样本）：dM0 89.9、dM4 80.7、dM5 72.9、
dM6 63.9、dM7 40.2、dM8 30.6 per cent。

**① S/N 匹配（10-30，亚型内）**：

| 亚型 | <100 pc | 200-400 pc |
|---|---|---|
| dM0 | 13.0 → 14.1（12,822） | 5.0 → 4.0（34,529） |
| dM3 | 23.6 → 20.3（5,879） | 11.6 → 6.5（4,604） |
| dM5 | 64.6 → 66.7（4,889） | 36.4 → 33.8（394；Wilson 29.3-38.6；占该格 2,617 的 15.1%） |
| dM6 | 74.8 → 75.9（790） | 52.6 → 22.2（9 颗，未定） |

**② 阈值不完备**：K_cat = median(ewha_err x snrr) = 0.749 A，把噪声加回后的"纯 S/N 效应"为
-0.05 ~ +0.16 百分点（S/N 19.7 对 12.3）；本地标定 K_loc = 2.177 A 给出 +0.02 ~ +0.13 百分点。
两者绝对值都 <= 0.17 点，远小于远档 16 点差（dM5 内 33 点），故"估计 < 0.2 点"成立。

**③ 单历元**：502,986 / 637,973 = 78.8%（正文 79%）；dM0 12.54→4.63、dM5 62.41→35.01、
dM6 73.79→50.51（99 颗）；倍数 1.46-2.82。

**④ 两张附录图**：变幅示例三颗星 5 / 8 / 22 个历元、峰峰值 4.95 / 4.95 / 4.88 A
（G17525452754071、G15492701691548、G16355010573835；8 历元那颗有 3 个同分候选）；
曝光采样：>=2 次曝光的 169,580 颗中恰好 2 次占 71.1%、少于 16 次占 99.75%，
间隔直方图首个 100 天箱 79,334 对（250,141 对的中位间隔 474 天）。

## 三点说明

1. **口径**：活动率一律基于 2D 逐星样本（每星一条最大 EW 谱），S/N 用目录 snrr 列；
   曝光/变幅用全目录（1,022,559 条谱、763,853 颗有 lmjd 的星）。
2. **两张图的示例星**由"峰峰值 + 历元数"反查得到（容差 0.02 A），8 历元那颗有 3 个候选，取 uid 排序
   第一个；图左栏的谱面需要 lrs 谱树，未随包交付，本流程只复现 EW 序列与图注数值。
3. **step4(a) 的 K_cat 与 s576 完全一致**（pass_act / pass_inact 逐档差 0.000，随机数种子 20261029，
   4000 条抽样 x 300 次）；step4(b) 复刻 s575 的调用顺序与种子，rel 与 s575 汇总表逐档一致。
