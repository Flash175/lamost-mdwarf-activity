# 复现流程（第一篇APJS）

把正文里可机读的数字整理成 **5 个可执行步骤**：每步直接读 `../数据/`（含 `原始输入/`），
结果写入 `输出/`，最后由 `step5_check_all.py` 与正文/摘要逐项比对并打印 PASS/FAIL。

## 快速开始

```powershell
cd 03_复现代码/复现流程
python run_all.py
```

- 全通过返回 0；有 FAIL 返回 2，明细见 `输出/step5_check.csv`。
- 可单跑指定步骤：`python run_all.py 2 3`（仍会执行第 5 步汇总）。
- 依赖：pandas、numpy、astropy。总耗时约 15 s，峰值内存约 3 GB（step1）。
