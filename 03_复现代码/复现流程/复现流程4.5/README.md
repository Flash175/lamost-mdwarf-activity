## 本轮按复现结果改正的两处正文数值

1. **`95, 55 and 0.02 per cent` → `97, 53 and 0.003 per cent`**：原数字在任何归档样本上都对不上；
   在正文统一使用的 **637,973** 冻结样本上按 G 分档重算（有 `radial_velocity` 即算覆盖）得 97.24 / 53.05 / 0.0031 %。
   参考：若不做视差质量与去重（并表后 997,156 行）则为 94.9 / 57.8 / 0.03 %——原数字接近这一口径但也不完全一致。
2. **`a factor of 7.7` → `a factor of 7.8`**：70.4288 / 9.0695 = 7.766，取一位小数是 **7.8**（原来 7.7 是用四舍五入后的 70.4/9.1 算的）。

## 说明

- σ 与 MAD 的标准误沿用归档口径：SE(std) = sqrt(σa²/2(na−1) + σi²/2(ni−1))，SE(MAD) ≈ sqrt((1.858σa)²/na + (1.858σi)²/ni)。
- 6D 的 |Z| 用 astropy 的银心 z（与 §3.3 一致），2D 用日心 d·sin b，两者不可混用。
- 正文关于"更冷 ≠ 更年轻"的定性讨论（Aumer 2016、Holmberg 2009、West 2011 的年龄定标）不含数字，本流程不设检查项。

## 本轮补进来的内容

1. **两类各自的绝对弥散与样本量**（`zmatch_kinematics.csv` 的 svz_act / svz_inact / *_mad 列）：
   0–25、25–50、50–75 pc 的 σ(vz) 活动星 **13.40 / 15.65 / 15.39**，非活动星 **19.49 / 19.68 / 19.78** km/s；
   MAD 活动星 8.65 / 9.92 / 10.21，非活动星 16.48 / 16.36 / 16.70 km/s。注意非活动星的弥散在三片之间几乎不变（19.5–19.8），这正是"固定 |Z| 比较"成立的直接证据。
2. **两张归档表互校**：用弥散列重算 Δσ 得 −6.0847 / −4.0273 / −4.3912 km/s，与 `kinematic_diff_errors.csv` 的 −6.0847 / −4.0273 / −4.3912 逐位相同（差 <1e−6 pp）。
3. **误差模型可复核**：SE(std)=√[σa²/2(na−1)+σi²/2(ni−1)] 与 SE(MAD)=√[(1.858σ)²/n] 重算后与归档 SE **完全一致**（0.2342/0.2832/0.2868 与 0.6154/0.7441/0.7535）。
   顺带确认：SE(MAD) 公式里的 σ 用的是**标准差**而非 MAD 本身（用 MAD 代入会得到 0.446 而不是 0.615）。
4. **40–80 pc 共同窗口**（正文"0–75 pc 内两估计量一致"的独立支撑）：Δσ(std) = −3.91 km/s（−16.8σ），Δσ(MAD) = −6.02 km/s（−9.8σ），两种估计量同号为负。

## 本轮补进来的内容：把速度弥散从原始数据重算一遍

原先的 σ(vz)、MAD、档中位都读自归档表 `zmatch_kinematics.csv`。现在流程**从原始目录 + Gaia 目录重建 6D 子样本**：
目录 → Gaia 并表（含视差、自行、径向速度）→ 视差质量/ruwe → 每 uid 取最大 EW → M_G≥6 → |Z_helio|≤3 kpc →
要求有 Gaia RV 且 |RV|<500 km/s → `SkyCoord.transform_to(Galactocentric())`（astropy 默认 R0=8.122 kpc、z_sun=20.8 pc、v_sun=(12.9,245.6,7.78) km/s）→ 取 |z_gc| ≤ 3 kpc，得 **82,518 颗**，与归档一致。

每个 |Z| 切片内对活动/非活动各自算 std 与 MAD（1.4826×中位绝对偏差），结果与归档表**逐位相同**：

| 切片 | σ(vz) 活动/非活动 | MAD 活动/非活动 | Δstd | ΔMAD | z(std) | z(MAD) |
|---|---|---|---|---|---|---|
| 0–25 pc | 13.404 / 19.488 | 8.654 / 16.478 | −6.085 | −7.824 | −25.98 | −12.71 |
| 25–50 pc | 15.651 / 19.678 | 9.923 / 16.356 | −4.027 | −6.433 | −14.22 | −8.65 |
| 50–75 pc | 15.390 / 19.781 | 10.209 / 16.703 | −4.391 | −6.495 | −15.31 | −8.62 |

误差与显著性也用独立重算的 SE 得到（SE(std)=√[σa²/2(na−1)+σi²/2(ni−1)]，SE(MAD)=√[(1.858σ)²/n]），与归档的 0.2342/0.6154 等完全一致。75 pc 以外的分歧（+1.9 / +0.7 / +5.9σ 与 −4.7 / −4.4σ）同样在重算中复现。

**结论：§4.5 的数字全部可由原始数据独立重算，未发现新的数据错误。**
