## 预期结果（实测 37/37 PASS）

| 亚型 | n | 活动率 (%) | Wilson 95% | 可探测比例 (%) |
|---|---|---|---|---|
| dM5 | 22,932 | 57.0 | 56.3–57.6 | 72.9 |
| dM6 | 3,671 | 72.9 | 71.4–74.3 | 63.9 |
| dM7 | 483 | 74.7 | 70.7–78.4 | 40.2 |
| dM8 | 85 | 65.9 | 55.3–75.1 | **30.6** |

S/N 匹配（dM6 对 dM7）：3–6 档 **73.6 / 76.0**；6–12 档 **71.9 / 68.9**；6–20 档 **73.4 / 75.3**，
三档区间都重叠。dM8 匹配后只剩 **15 / 6 / 7** 条谱（正文 "6–15"）。

活动率从 dM5 到 dM6 上升（57.0 → 72.9）而可探测比例同时下降（72.9 → 63.9），所以这个上升不能由探测能力解释。

**区间检验**：dM6 与 dM7 的 Wilson 区间重叠（71.4–74.3 对 70.7–78.4）；三档 S/N 匹配后仍重叠
（3–6：70.9–76.2 对 67.7–82.8；6–12：68.7–74.8 对 56.4–79.1；6–20：71.0–75.7 对 65.4–83.1）；
dM7 与 dM8 也重叠（70.7–78.4 对 55.3–75.1）。dM5→dM6 的上升两比例 **z = 18.2**，所以正文说这个上升是真实的。

## 两点说明

1. **口径**：全部基于 2D 逐星样本（637,973 颗，每星一条最大 EW 谱）；可探测比例 = 3σ(EW) ≤ 0.75 Å 的星占比。
2. **S/N 区间与 s551 一致**：3–6 与 6–12 为半开区间（[lo, hi)），6–20 为闭区间（[6, 20]）；
   若把前两档也写成闭区间，会得到 73.5/76.2 与 71.9/68.9，与正文差 0.1–0.2 个百分点。
